# 하운드 PDF (탭)

갤럭시 탭에서 인터넷 없이 기록을 보고 S펜으로 표시하는 웹앱(PWA). 2026-10-30 팀장님 요청.

## 되는 것
- PDF 열기(탭 안 파일, 마이박스 오프라인 사본 포함), 최근 연 파일 8개(이 탭 브라우저 안에만 사본, [목록 비우기]로 지움)
- 왼쪽 [책갈피](기록철 책갈피 그대로, 단계별 들여쓰기) [쪽](쪽 그림), 쪽 번호로 가기, 확대, 축소, 높이 맞춤, 두 손가락 확대(열면 늘 높이 맞춤, 바꾼 확대는 그 파일 동안만)
- 쪽 보기 [한 쪽][두 쪽](PC 하운드 PDF와 같은 이름, 2026-10-30): 고른 적이 없으면 가로 화면 두 쪽, 세로 한 쪽(고르면 이 탭에 기억). 두 쪽에서 [첫 쪽 따로](표지, 기본 켬). 쪽 넘기기(PageDown, →)는 두 쪽씩, 책갈피와 쪽 번호는 그 쪽이 든 줄로. [높이 맞춤] = 쪽(두 쪽이면 그 줄)이 화면 높이에 꼭 맞게, 폭도 넘지 않게(PC 하운드 PDF와 같음). 펜 좌표는 쪽마다 따로라 두 쪽에서 그려도 저장 위치 같음.
- 넘기기 [쪽 넘김][스크롤](2026-10-30): 쪽 넘김은 한 화면에 한 줄(한 쪽 또는 두 쪽)만, 손가락으로 밀기나 화면 양 끝(15%) 누르기로 넘김, 확대한 동안은 밀어도 안 넘어가고 쪽 안을 움직임. 실제 탭에서 반응이 없어(판 6) 포인터 이벤트로 받고 쪽 넘김 화면은 touch-action: none(브라우저가 손동작을 가져가지 않게), 끊기면(pointercancel) 마지막 자리로 판단(판 7).
- 증거번호 누르기(2026-10-30, PC 기록철 evidence.py와 같은 규칙 `app/evidence.js`): 본문 글자의 '갑 제1호증', '을 제2호증의 1', '(갑 1-2)' 등과 PDF 안 링크에 옅은 밑줄. 손가락(또는 도구가 꺼진 마우스)으로 누르면 책갈피에서 그 증거 쪽을 찾아 가로 화면은 오른쪽 반, 세로는 아래 반에 보여 줌([앞 쪽][다음 쪽][−][+][이 쪽으로][닫기]). 가지번호가 여럿이면 위에서 고르기. S펜으로 짧게 누르면(6px, 0.35초 안) 증거 글자는 옆에 보기, 쪽 넘김 화면 양 끝은 넘기기(점을 찍지 않음), 그으면 그대로 그려짐(판 7). 시험 `python tests/evidence_parity.py`(PC 규칙과 결과 비교).
- 새 판이 올라가면 앱 오른쪽 아래 '새 판이 있어요 [다시 열기]'.
- S펜: 펜, 형광펜, 밑줄(곧은 가로선), 지우개(이번에 그린 것), 되돌리기. 손가락은 넘기기, 펜은 그리기
- 저장: PDF 표준 Ink 주석(모양 그림 포함)이라 PC 하운드 PDF, 다른 PDF 프로그램에서도 같게 보임
  - [저장]: 덮어쓰기가 되는 브라우저(PC 크롬)는 그 파일에, 안드로이드는 같은 이름으로 '다운로드' 폴더에
  - [다른 이름]: 새 이름으로
- 인터넷 없이 동작(서비스 워커가 앱 파일을 저장). 바깥으로 보내는 요청 없음

- 판 번호: 처음 화면과 [보기] 창 아래에 '판 N'(app.js APP_VER, sw.js VERSION과 같이 올림).

## 폴더
- `app/` 올릴 폴더 전체(정적 파일만). pdf.js 3.11.174, pdf-lib(`app/vendor`, Hound-cases static/vendor와 같은 파일)
- 앱 파일을 고치면 `app/sw.js`의 `VERSION`을 올린다(탭이 새 판을 받음)
- `tests/make_fake.py` 시험용 가짜 통합기록 PDF

## 탭에 까는 법
1. `app/` 폴더를 HTTPS 주소에 올린다(서비스 워커는 HTTPS에서만 동작). 올리는 곳은 팀장님 확인 뒤.
2. 탭 크롬에서 그 주소를 한 번 열고, 메뉴 > '홈 화면에 추가'(또는 '앱 설치').
3. 그 뒤로는 홈 화면 아이콘으로 인터넷 없이 켜진다.

## 시험(PC)
```
python -m http.server 47410 --bind 127.0.0.1 --directory C:\Hound\Hound-pdf-tab
```
브라우저에서 `http://localhost:47410/app/` (localhost는 HTTPS 없이도 서비스 워커가 됨).
